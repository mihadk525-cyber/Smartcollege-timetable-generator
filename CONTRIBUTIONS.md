# Team contributions

Maximum 3 members, same batch. Edit this file with your real names and work done.

| Member | Area | Files |
|---|---|---|
| Member 1 | DSA core: conflict graph, DSATUR, backtracking solver | `backend/scheduler/` |
| Member 2 | Backend + database: API, models, validator, tests | `backend/app.py`, `models.py`, `seed.py`, `database/` |
| Member 3 | Frontend + docs: React UI, README, export | `frontend/`, `docs/` |

Everyone should be able to explain the whole workflow (frontend -> API -> database -> solver) and their own part in detail.
Use branches (for example `feature/solver`, `feature/api`, `feature/ui`) and commit under your own name.
